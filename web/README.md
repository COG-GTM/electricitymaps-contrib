# Electricity Maps — Web Frontend

Interactive React + TypeScript visualization of grid carbon intensity by zone,
built on the static datasets produced by the parsers and config in this repo.

## Stack

- React 18 + TypeScript
- Vite (dev server + production build)
- MapLibre GL via `react-map-gl/maplibre`
- Recharts for production-mix charts

## Data pipeline

The frontend reads four static files served from `web/public/` (the Vite
`public/` root):

| File | Source | Generated by |
|---|---|---|
| `zones.json` | `config/zones/*.yaml` | `web/scripts/generate_web_data.py` |
| `exchanges.json` | `config/exchanges/*.yaml` | `web/scripts/generate_web_data.py` |
| `world.geojson` | `geo/world.geojson` | copied by `generate_web_data.py` |
| `mock-data.json` | captured grid-state JSON + zone capacity configs | `web/scripts/generate_real_data.py` |

To regenerate everything:

```bash
cd web/scripts
uv run python generate_web_data.py
uv run python generate_real_data.py
```

## Develop

```bash
cd web
npm install
npm run dev          # http://localhost:5173
```

## Build

```bash
cd web
npm run build        # type-check + vite build  → web/dist/
npm run preview      # serve the production build
```

## Project layout

```
web/
├── public/                     # Static data files served from site root
├── scripts/                    # Python data-generation scripts
└── src/
    ├── components/
    │   ├── Map/                # MapLibre map, exchange arrows, hover tooltip
    │   ├── Panel/              # Zone detail panel + production-mix chart
    │   ├── Legend/             # Carbon-intensity color legend
    │   └── BottomBar/          # Time slider
    ├── context/                # AppContext: zones, exchanges, time, selection
    ├── hooks/                  # useZones / useExchanges / useGridData / useGeoJson
    ├── types/                  # TypeScript interfaces mirroring the JSON
    └── utils/                  # Color scale + emission-factor calculations
```
